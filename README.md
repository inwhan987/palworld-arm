# palworld-arm

ARM64 리눅스(오라클 Ampere A1 · 라즈베리파이)에서 **팰월드 전용 서버**를 한 줄로 세우는 설치 스크립트.

팰월드 서버 바이너리는 x86 전용이라 ARM에서 그냥은 돌지 않습니다. 여기서는 FEX 에뮬레이션이 들어간 `supersunho/palworld-server` 이미지를 쓰고, 그 위에 운영에 필요한 것들을 얹습니다.

## 설치

Ubuntu 22.04 / 24.04 (ARM64) 를 올린 서버에 SSH로 접속한 뒤:

```bash
curl -fsSL https://raw.githubusercontent.com/inwhan987/palworld-arm/main/install.sh -o install.sh
bash install.sh
```

기존 세이브를 가져오려면 백업 파일을 인자로 넘깁니다:

```bash
bash install.sh ~/save_20260916_050000.tar.gz
```

`sudo` 를 붙이지 마세요. 필요한 곳에서만 스크립트가 알아서 씁니다.

처음 2분 동안 질문 몇 개에 답하면, 그 뒤는 자리를 떠도 됩니다. 게임 본체 내려받기까지 끝나면 서버가 자동으로 켜집니다.

## 설치가 물어보는 것

```
서버 이름 / 접속 비밀번호 / 관리자 비밀번호
디스코드 웹후크 (없으면 엔터)
최대 인원 · 경험치 배율 · 포획 확률
정기 점검 시각 · 업데이트 자동 적용 여부 · 확인 주기
```

나머지 설정은 기본값으로 채워지고, 나중에 `.env.palworld` 에서 바꿀 수 있습니다.

## 설치 뒤에 생기는 것

| 명령 | 하는 일 |
|---|---|
| `pal apply` | 설정 적용 — **바뀐 항목을 디스코드로 알림** |
| `pal stop` / `pal restart` | 종료 / 60초 예고 후 재시작 |
| `pal update` | 도커 이미지 업데이트 (패치 자동 재생성) |
| `pal update-game` | 팰월드 본체 업데이트 (백업 후 재설치) |
| `pal status` / `pal log` | 상태 확인 / 로그 보기 |
| `palup` | 업데이트가 **있을 때만** 즉시 적용 |

크론 세 줄도 함께 등록됩니다.

| 주기 | 하는 일 |
|---|---|
| 10분 | `watchdog.sh` — 컨테이너 감시, 20분 넘게 비정상일 때만 알림 |
| 매시 | `checkupdate.sh --notify` — 새 빌드 확인, 빌드당 한 번만 알림 |
| 매일 | `nightly.sh` — 업데이트 있으면 적용, 없으면 재시작 |

## 코드 패치

이미지에 없는 동작 세 가지를 `make-patches.sh` 가 만들어 넣습니다. 이미지 원본을 꺼내 수정하는 방식이라, 이미지가 바뀌어도 다시 돌리면 됩니다.

| 파일 | 고치는 것 |
|---|---|
| `server_manager.py` | 기동 완료 시 🟢 시작 알림 전송 |
| `healthcheck.py` | RCON 검사의 `--password-stdin` → `--password` |
| `server_monitor.py` | 무인 경고를 `IDLE_WARNING_ENABLED` 로 제어 |

패치가 새 이미지와 맞지 않으면 생성 단계에서 멈추고, 알림만 빠진 채 서버는 정상 동작합니다.

## 클라우드 방화벽

인스턴스 안쪽 `iptables` 는 스크립트가 엽니다. 클라우드 콘솔 쪽 규칙은 직접 만들어야 합니다.

| | |
|---|---|
| IP 프로토콜 | UDP |
| 대상 포트 범위 | 8211 |
| 소스 CIDR | 0.0.0.0/0 |
| 소스 포트 범위 | **비워둘 것** |

소스 포트 범위에 8211을 넣으면 모든 접속이 차단됩니다. 게임 클라이언트는 무작위 포트에서 접속하기 때문입니다.

## 라즈베리파이

같은 ARM64라 그대로 돕니다. 다만 FEX 에뮬레이션이 CPU를 많이 먹으니 **8GB 이상 + SSD** 를 권합니다. 마이크로SD는 세이브 손상 위험이 큽니다.

## 주의
